Change log

1.9.1

  • Sends the referring page (Referer).
  • Transparent GIFs show the page behind them, including dark table cells.
  • Out of memory handling improved: warning dialog, about page.
  • Page history restores form data when moving back or forward.
  • About page: new layout, and Check for updates.

1.9

  • Added printing, w/ page-aware layout and options for headers and footers.
  • Warn the user if they change a form and attempt to navigate or close prior to submit.

1.8.1

  • Address bar alignment adjustments for descenders and icon centering.

1.8

  • More than one window: New Window (Command-N) and Close (Command-W) in the File menu. Closing the last window leaves Mill running.
  • Open Link in New Window, in a link's context menu.
  • While a page loads, other windows still redraw.
  • Addresses with :// later in them, as in a query (?url=http://...), open.

1.7.2

  • A User agent setting. The default is now Mozilla/1.22 (compatible; Mill/1.7.2; Macintosh; 68K).
  • Text fields and the address bar scroll sideways to follow the cursor and a dragged selection; text areas scroll with a dragged selection too.

1.7.1

  • Settings has General, Proxy, and Bookmarks sections.
  • An Enable proxy setting.
  • Proxy excluded domains can also list IP addresses and ranges (192.168.0.0/16).
  • Text areas have scroll bars.

1.7

  • Proxy support, with excluded domains.
  • https:// addresses through the proxy.
  • Form controls marked DISABLED are dimmed and not sent.

1.6.1

  • Images that haven't loaded load from the context menu only; clicking follows the link.
  • Cross-protocol links limited only to file: or mill:.
  • Shorter, plainer text on Mill's own pages and in its messages.

1.6

  • HTTP Basic and Digest authentication, with a name and password dialog.
  • Addresses with a name and password (http://name:password@host/); the address bar hides them.
  • Bookmarks can save a page's name and password ("Save name and password").

1.5.4

  • Table cells with a dark BGCOLOR are drawn black with white text, as in a navigation bar.

1.5.3

  • Images with ALIGN=LEFT or RIGHT float, with text wrapping beside them; BR CLEAR moves below them.

1.5.2

  • A stop sign replaces the reload button while a page loads.
  • New tagline: "A web browser for classic Macs".

1.5.1

  • Command-period stops loading at any stage, not just the name lookup.
  • Escape (or Clear) stops loading too.
  • Keys like Escape no longer go into the address bar.

1.5

  • Image maps, client-side (USEMAP) and server-side (ISMAP); the status line shows where each area goes.
  • ISINDEX search fields.
  • A border on the status message.

1.4

  • View Source, from the context menu or as a view-source: address.
  • View Image, from the context menu.
  • Plain text pages show < and & as written.

1.3

  • Bookmarks menu, Command-1 to Command-0, with Command-D to add.
  • The status line changed to pop over.
  • The horizontal scroll bar hidden if not needed.

1.2

  • Support for System 6.0.8.

1.0.1

  • A new Finder icon.

1.0

  • Optional click-to-load images, with decoding progress.
  • Downloads with Mac type and creator rules and MacBinary decoding.
  • Context menu to load or save images, save links, and save page source.
  • Page size limit of 192K.
  • Horizontal scrolling.
  • UTF-8 encoding.
  • Basic cookie support.
  • OSS license terms added to mill://license.
  • A faster splash screen.

0.4

  • Built-in pages: mill://about and mill://config.
  • Local files: file://
  • Forms, with GET, POST, and file uploads.
  • Image cache memory.
  • Links, forms, and images not loaded cross-protocol.

0.3

  • Tables, and GIF and JPEG images dithered for monochrome screens.
  • Splash screen while loading.
  • Name lookup timeout.

0.2

  • HTML layout, with links, history, and redirects.
  • Back, forward, and reload buttons, the turning windmill, and the status line.

0.1

  • Fetches a page over MacTCP and shows it as text.
